Falta configurar a base de dados

Antes de usar a aplicação, é preciso ligar ao Supabase. Siga o GUIA-PUBLICAR.md incluído, depois:

  1. Abra este ficheiro index.html num editor de texto
  2. Encontre a linha com SUPABASE_URL e SUPABASE_ANON_KEY
  3. Substitua pelos valores do seu projeto Supabase
  4. Volte a carregar o ficheiro (ou publique-o novamente no GitHub)
